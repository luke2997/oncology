# Disclaimer

This repository is a simulated clinical-trial statistical submission portfolio. All subjects, dates, outcomes, adverse events, and laboratory values are synthetically generated for demonstration only. The repository contains no real patient data, no PHI, and no proprietary sponsor information.

The project is designed to demonstrate biostatistics/statistical-programming competence: protocol/SAP thinking, ADaM-style analysis datasets, TLF production, survival analysis, safety summaries, QC checks, and submission-style documentation.
