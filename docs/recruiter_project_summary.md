# Recruiter-facing project summary

## What this portfolio proves

- Designed a complete simulated Phase III oncology statistical submission workflow.
- Generated reproducible synthetic trial data with randomization, PFS, OS, tumor response, exposure, AEs, and lab shifts.
- Built ADaM-style ADSL, ADTTE, ADAE, ADRS, and ADLB datasets with analysis flags and derived variables.
- Produced submission-style TLFs, listings, figures, protocol synopsis, SAP, clinical analysis report, metadata, and validation report.
- Implemented Kaplan-Meier estimates, log-rank tests, Cox proportional hazards models, exact binomial confidence intervals, TEAE summaries, lab shifts, and QC checks.

## CV bullets
